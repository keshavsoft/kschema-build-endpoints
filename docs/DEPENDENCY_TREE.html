Dependency tree and package story

KSchema turns Express endpoint files into a reusable endpoint story.

The system is a small package graph: infrastructure finds and reads files, endpoint packages understand project conventions, parser packages turn JavaScript lines into structured method stories, and the top-level builder merges those stories into endpoint knowledge.

Overall story

Discover, read, parse, merge.

kschema-build-endpoints coordinates the work. It asks kschema-pull-endpoints for endpoint paths, reads those files with node-fs-read-content, then asks kschema-pull-methods to extract method stories. The output is a combined endpoint story that can feed docs, graphs, Swagger, and future build packages.

Execution flow

From source folder to endpoint knowledge

Each package owns one job, so the graph stays easy to extend and test.

1

Discover endpoint files

kschema-pull-endpoints searches project folders using node-fs-recursive.

2

Read file content

node-fs-read-content converts paths into objects containing file metadata and text.

3

Pull JavaScript lines

pattern-collector-anyjs finds import, export, consumption, and all matched lines.

4

Build method stories

kschema-pull-methods maps parsed lines into method, endpoint, function, and line data.

5

Merge endpoint story

kschema-build-endpoints returns one model with endpoint content and method content.

Architecture story

Why the dependency direction matters

The graph points downward: higher-level packages can depend on lower-level packages, but lower-level packages do not know about endpoint or Express concepts.

Infrastructure

Files are just files

node-fs-recursive and node-fs-read-content stay reusable because they only know folders, paths, and content.

Project conventions

Endpoint paths are found

kschema-pull-endpoints understands where endpoint files live without parsing business logic.

Pattern parsing

JavaScript lines become facts

The pattern collector family extracts imports, exports, usage, and regex matches as structured line data.

Knowledge building

Facts become stories

kschema-build-endpoints assembles endpoint content and method content into a model for docs and graphs.
